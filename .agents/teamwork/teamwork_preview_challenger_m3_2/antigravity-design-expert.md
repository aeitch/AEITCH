# antigravity-design-expert (Local Copy)
Core UI/UX engineering skill for building highly interactive, spatial, weightless, and glassmorphism-based web interfaces using GSAP and 3D CSS.

Summary of methodology:
- Weightlessness, spatial depth (Z-axis, perspective), glassmorphism (backdrop-filter blur, subtle borders).
- Smooth transitions (>= 0.3s ease-out), staggered entrances, reduced-motion consideration.
- Performance: will-change: transform, avoid animating box-shadow/filter continuously.
